# 🤖 Бункер IT — Настольная игра (Web-версия)

Веб-приложение для проведения партий в настольную игру **«Бункер IT»** на колоде из 300 тематических IT-карт.
Разработано на стеке **Node.js 22 + Express + React + Vite + Tailwind CSS**.

---

## 🚀 Варианты развертывания на VPS

### Вариант 1. Запуск через Docker Compose (Рекомендуется)

1. Клонируйте репозиторий на ваш сервер:
   ```bash
   git clone https://github.com/nericovich/IT-main.git
   cd IT-main
   ```

2. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```

3. Приложение будет доступно по адресу `http://ВАШ_IP:3000`.  
   Все игровые партии сохраняются в постоянный Docker Volume `bunker_data`, поэтому перезапуск контейнера не сбрасывает текущую игру.

---

### Вариант 2. Запуск через Docker (одиночная команда)

```bash
docker build -t bunker-it .
docker run -d \
  --name bunker-it \
  --restart unless-stopped \
  -p 3000:3000 \
  -e BUNKER_GM_PASSWORD="ваш_пароль_ведущего" \
  -v bunker_data:/app/data \
  bunker-it
```

---

### Вариант 3. Прямой запуск через Node.js (без Docker)

Требуется установленный **Node.js 20+** и **npm**:

```bash
git clone https://github.com/nericovich/IT-main.git
cd IT-main

# Установка зависимостей
npm install

# Сборка клиентской и серверной части
npm run build

# Запуск в продакшене (порт 3000)
npm start
```

Для фонового запуска рекомендуется использовать **PM2**:
```bash
npm install -g pm2
pm2 start dist/server.cjs --name "bunker-it"
pm2 save
pm2 startup
```

## 🌐 Настройка Nginx и SSL (домен)

Пример конфига Nginx (`/etc/nginx/sites-available/bunker`):

```nginx
server {
    server_name bunker.example.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Сертификат SSL выпускается бесплатно через Certbot:
```bash
sudo certbot --nginx -d bunker.example.com
```

## ⚙️ Переменные окружения (`.env`)

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | Порт, который слушает сервер |
| `BUNKER_GM_PASSWORD` | Задаётся пользователем | Пароль для входа в панель Ведущего |
| `DATA_DIR` | корень приложения | Путь для сохранения файла состояния `.bunker_session.json` |

## 🎮 Механика игры и перков

В игре предусмотрено 2 режима:
1. **Табло игроков**: Публичное табло для демонстрации на проекторе или смартфонах участников. Отображает только те характеристики, которые открыл ведущий. Обновляется в реальном времени.
2. **Панель Ведущего** (вход защищён паролем):
   - Генерация стола на 2–30 человек с 0–5 перками.
   - Пораундовое раскрытие характеристик («Открыть всем Профессию», «Открыть всем Биологию» и т.д.).
   - Применение **всех 30 игровых перков**:
     - *«Аутсорсинг риска» / «Экстренное внедрение»* — заменяет карту Угрозы на новую из колоды.
     - *«Хедхантинг»* — интерактивный обмен Профессиями между двумя выбранными игроками.
     - *«Глубокий рефакторинг»* — сброс и перетягивание карты Здоровья.
     - *«Переезд на удаленку»* — сброс и перетягивание Биологии.
     - *«Архитектурный комитет»* — обмен картами Багажа.
     - *«Кумовство» / «Раунд инвестиций»* — возвращение исключённого игрока обратно в игру.
     - *«Code Review (План Б)»* — аннулирование результатов голосования и возвращение выбывших за стол.
     - *«Душный синьор»* — перераздача карт Хобби всем участникам.
     - *«Внезапная смена ТЗ»* — перераздача выбранной категории всем игрокам.
     - *«Ctrl + Z»* — отмена любого сыгранного перка.
     - *«Тайный оффер», «Забастовка», «Золотой парашют», «Парное программирование»* — установка статусных бейджей защиты и иммунитета на карточки игроков.
     - *«Деплой в прод без тестов»* — экстренный переход к голосованию.
     - Возможность отозвать применение любого перка.
   - Встроенный таймер раундов на 30, 60, 90 и 120 секунд со звуковым сигналом.
   - Просмотр и поиск по всей колоде из 300 IT-карт.
